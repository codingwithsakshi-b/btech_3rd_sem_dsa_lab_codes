## 📌 About This Repository

Welcome to my **DSA Lab Programs** repository! 👋

This repository contains C++ programs written while learning and practising fundamental programming concepts, searching and sorting algorithms, recursion, matrices, and basic data structures.

The goal of this repository is to maintain my lab programs in one place, strengthen my problem-solving skills, and document my progress as a Computer Science and Engineering student.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/codingwithsakshi-b/btech_3rd_sem_dsa_lab_codes.git
```

### 2. Open the Project Folder

```bash
cd btech_3rd_sem_dsa_lab_codes
```

### 3. Compile a Program

For example, to compile the binary search program:

```bash
g++ binary_search.cpp -o binary_search.exe
```

### 4. Run the Program

On Windows PowerShell:

```powershell
.\binary_search.exe
```

**Note:** Replace `binary_search.cpp` and `binary_search.exe` with the relevant source and executable filenames when running another program. Some programs require user input through the terminal.
